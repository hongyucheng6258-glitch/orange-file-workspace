集成详情

1. 命令面板 (Ctrl+K)

  • AppShell.tsx — 添加 useCommandPalette hook，注册 12 个导航命令
  • Topbar.tsx — 添加 onCommandPaletteToggle prop 和「Ctrl K」提示按钮
  • 全局 Ctrl+K 快捷键由 hook 内部监听，无需额外配置
  • 命令分类：导航（9 个）+ 操作（3 个），覆盖所有主要路由

2. 最近访问列表

  • HomePage.tsx — 在仪表板底部添加 RecentItemsList 区块
  • 支持按资源类型筛选（文件、文件夹、页面、项目）
  • 点击项目自动导航到对应路由
  • 显示最近 10 条访问记录

3. 标签管理

  • DetailPanel.tsx — 添加可折叠的「标签」区域
  • TagManager 组件新增 embedded 模式，适配面板内嵌
  • 点击资源详情面板的「标签」按钮即可展开/收起
  • 支持创建、删除、颜色选择、关联/取消关联

4. Git 状态

  • ProjectPage.tsx — 在文件树侧栏底部添加可折叠 Git 面板
  • 选择项目时自动获取项目路径并传入 GitStatus
  • 显示分支、ahead/behind、文件状态（暂存/未暂存）
  • 支持按状态筛选（全部/新增/修改/删除/冲突等）

5. 工作区会话

  • 新建 ProjectSessionManager.tsx — 纯逻辑组件，无渲染
  • 项目打开时自动恢复上次打开的文件
  • 文件打开/关闭后 800ms 防抖自动保存会话
  • 项目切换时自动更新最后访问时间
