# C 盘双模式清理脚本设计

日期：2026-08-18
状态：已批准

## 目标

生成独立 PowerShell 脚本，为 Windows 提供安全清理和深度清理两种模式。默认安全模式，所有删除均基于固定白名单；先扫描、后选择、再确认，不触碰用户文档与浏览器隐私数据。

## 命令接口

- 默认运行：安全模式，交互选择后清理。
- `-Mode Safe|Deep`：选择清理模式，默认 `Safe`。
- `-ScanOnly`：只扫描并输出结果，不删除任何内容。
- `-IncludeIds <id[]>`：明确指定清理项，供后续 Tauri 集成；交互运行时由菜单生成。
- `-Force`：跳过普通确认，但回收站仍要求明确授权参数。
- `-ConfirmRecycleBin`：允许清空回收站；未提供时即使选中也拒绝执行。
- `-OutputJson`：输出机器可读 JSON 结果。

## 清理范围

### 安全模式

- 当前用户临时目录。
- Windows 临时目录中当前权限可删除的内容。
- Explorer 图标缓存与缩略图缓存。
- Edge、Chrome、Firefox 的普通缓存目录。
- 回收站，默认选中，但必须明确二次确认。

### 深度模式新增

- Windows 错误报告归档和队列。
- 用户及系统崩溃转储。
- Windows 更新下载缓存。
- Delivery Optimization 缓存。

深度模式扫描后逐项选择，默认只选低风险项目。需要管理员权限的项目展示但不默认选择。

## 浏览器边界

只清理 Chromium 的 `Cache`、`Code Cache`、`GPUCache`、`Service Worker\\CacheStorage`，以及 Firefox profile 下的 `cache2`。不匹配或删除 Cookie、Login Data、History、Web Data、Local Storage、IndexedDB、Sessions、Bookmarks 和用户配置。

## 安全约束

- 每个清理项必须由代码内白名单定义，调用方不能传入任意路径。
- 路径解析后不得是盘符根目录、用户主目录、Windows 根目录或浏览器 profile 根目录。
- 默认先扫描；`-ScanOnly` 不调用任何删除 API。
- 符号链接和重解析点不递归进入。
- 被占用、权限不足和消失的文件跳过并计数。
- 回收站清空不可恢复，必须单独确认。
- 不修改注册表、系统还原点、启动项、下载目录、桌面或用户文档。

## 输出

每项输出候选文件数、预计字节数、删除文件数、释放字节数、跳过数和错误摘要；整体输出模式、管理员状态、开始结束时间及总计。退出码：成功 `0`，部分跳过 `2`，参数或安全校验失败 `1`。

## 验收

- 默认模式为 `Safe`。
- `-ScanOnly` 执行后文件系统不发生删除。
- 普通缓存规则不包含浏览器隐私数据路径。
- 危险根路径被安全校验拒绝。
- 回收站无独立确认时不执行。
- Windows PowerShell 5.1 可解析并运行。
